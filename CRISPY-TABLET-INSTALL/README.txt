CRISPY Printer — Android tablet
================================

Install the file:

  CRISPY-Printer.apk

1. Send CRISPY-Printer.apk to the Android tablet.
2. Download it.
3. Open the APK.
4. If Android blocks installation, allow "Install unknown apps" for the app used to open it.
5. Install CRISPY Printer.
6. Open it once.
7. Approve the notification permission and the battery prompt.
8. Connect the tablet to the same reachable local network as printer 192.168.1.87.
9. Press "اختبار الطباعة".
10. Confirm that physical paper came out.
11. In settings, enter the agent token and press "حفظ".
12. In the CRISPY admin printer page, confirm the agent shows ONLINE.

The first local test does not need a customer order, Windows, or Firebase.
Production orders print only after the agent token is saved.

After installation, open the app once. Android may require that again after a reboot before background printing resumes.

The printer stays on the local network. Do not forward port 9100 to the internet.
